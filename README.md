# 🐉 Rayquaza Frontend

> Frontend interface for the **Rayquaza Intelligent Multi-Model Orchestration Architecture** developed by **Team Arceus** for the **AI Innovation Hackathon 2026**.

---

## 📌 Overview

Rayquaza is an intelligent multi-model orchestration system designed to reduce AI infrastructure costs through smart routing, batching, and real-time monitoring.

This repository contains the **frontend dashboard** used to monitor the AI cluster, visualize routing decisions, measure batching efficiency, and manage system telemetry.

---

## ✨ Features

- 🖥️ Central Telemetry Dashboard
- 📊 Route Check Engine
- 📈 Route Accuracy Monitoring
- ❌ Wasteful Route Detection
- 💰 Batching Cost Comparison
- ⏱️ Time Saving Analysis
- 🚦 Automatic Intake Limiter
- 📡 Live Prompt Route Inspector
- 📉 Queue Monitoring
- ⚡ Traffic Spike Simulation
- 🎨 Cyberpunk Inspired UI

## 🚀 Getting Started

### Prerequisites

Install the following:

- Node.js (v18 or later)
- npm

Check versions

```bash
node -v
npm -v
```

---

## 📥 Installation

Clone the repository

```bash
git clone <repository-url>
```

Move into the project

```bash
cd frontend
```

Install dependencies

```bash
npm install
```

---

## ▶️ Run Development Server

```bash
npm run dev
```

Open

```
http://localhost:5173
```

---

## 🏗️ Build Production Version

```bash
npm run build
```

---

## 👀 Preview Production Build

```bash
npm run preview
```

---

## 🔗 Backend Requirement

This frontend communicates with the Rayquaza backend server.

Before running the application, make sure the backend server is running and accessible.

Update the backend API endpoint if necessary.
